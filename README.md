# Tasteful Delights Bites — Preorder Site

Next.js site hosted on Vercel with a Supabase (Postgres) database.

Settings Vercel needs:
- `POSTGRES_URL` — added automatically when Supabase is connected to the Vercel project
- `ADMIN_PASSWORD` — the password for /admin

After the first deploy, log in at `/admin` and tap **Set up my database**.
